# Безопасность при работе с Arc Testnet

## Основные правила

1. **Никогда** не вводи seed-фразу на подозрительных сайтах.
2. Проверяй URL перед подключением кошелька.
3. Используй отдельный кошелёк для тестнета.
4. Не одобряй бесконечные аппрувы без необходимости.
5. Регулярно отзывай аппрувы (используй revoke.cash).

## Полезные инструменты

- **Revoke.cash** — отзыв аппрувов
- **DeBank** или **Zapper** — отслеживание активностей
- **Wallet Guard** / **Scam Sniffer** — проверка dApp

**Красные флаги:**
- Сайты, которые просят подключиться и сразу отправить токены
- Слишком заманчивые обещания airdrop
- Неизвестные контракты
