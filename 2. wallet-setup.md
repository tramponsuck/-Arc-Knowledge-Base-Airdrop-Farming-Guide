# Настройка кошелька для Arc

## Рекомендуемые кошельки

| Кошелёк          | Рекомендация     | Почему удобен                  |
|------------------|------------------|--------------------------------|
| Rabby Wallet     | ★★★★★            | Лучший для мультичейна         |
| MetaMask         | ★★★★             | Самый популярный               |
| Bitget Wallet    | ★★★★             | Хорош для мобильного фарминга  |
| OKX Wallet       | ★★★              | —                              |

## Лучшие практики

1. Создай **новый** кошелёк специально под Arc (не используй основной).
2. Сделай бэкап seed-фразы.
3. Никогда не подключай основной кошелёк с большими суммами.
4. Включи 2FA где возможно.
5. Используй hardware wallet (Ledger/Trezor) для больших объёмов.

## Как переключиться на Arc Testnet

- Выбери сеть Arc Testnet в кошельке.
- Убедись, что в балансе отображается USDC.
