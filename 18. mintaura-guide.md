# 18. Mintaura — NFT Minting

## О проекте
Платформа для создания и минтинга NFT на Arc.

## Как использовать

1. Перейди на сайт Mintaura
2. Подключи кошелёк + Arc Testnet
3. Создай коллекцию или используй готовую
4. Заминть несколько NFT

**Рекомендация:** Минт NFT — хорошее дополнение к другим активностям.
