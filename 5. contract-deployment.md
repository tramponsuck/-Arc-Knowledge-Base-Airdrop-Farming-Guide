# 5. Деплой смарт-контрактов

## Пошаговая инструкция (Remix)

1. Открой [remix.ethereum.org](https://remix.ethereum.org)
2. Создай файл `TestToken.sol`
3. Вставь код ERC-20 (см. пример ниже)
4. Скомпилируй
5. Выбери Injected Provider
6. Подключи Arc Testnet
7. Нажми Deploy

**Пример простого ERC-20:**
```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;
import "@openzeppelin/contracts/token/ERC20/ERC20.sol";

contract ArcTestToken is ERC20 {
    constructor() ERC20("ArcTestToken", "ATT") {
        _mint(msg.sender, 1000000 * 10 ** decimals());
    }
}
