# Arc Knowledge Base & Airdrop Farming Guide

**Полный гайд по Arc (Circle) Testnet** — максимум информации в одном месте.

> Arc — это L1 блокчейн от Circle (создатели USDC). Native gas token — **USDC**.  
> Цель — стать "Economic OS" для stablecoins, RWA и институционального DeFi.

**Статус на май 2026**: Public Testnet активно работает. Mainnet ожидается в 2026 году.  
Потенциальный airdrop / ретродроп ARC token — один из самых ожидаемых в 2026 году.

## 🎯 Что даёт максимальную ценность для потенциального дропа

1. Разнообразная on-chain активность (не только свопы).
2. Взаимодействие с разными dApps (Curve, Synthra, ZNS, OmniHub и др.).
3. Mint доменов `.arc`.
4. Создание и минт NFT.
5. Деплой смарт-контрактов.
6. Участие в Arc House (очки + задания).
7. Bridge + Liquidity providing.

**Важно**: Избегай явного sybil-атак. Делай всё естественно и в разное время.
