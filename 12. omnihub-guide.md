# 12. OmniHub на Arc Testnet

## О проекте
Многофункциональная платформа: Faucet, NFT Launchpad, Bridge.

**Главные ссылки:**
- Faucet: [https://omnihub.xyz/faucet/arc-testnet](https://omnihub.xyz/faucet/arc-testnet)
- Create NFT: [https://omnihub.xyz/create/arc-testnet](https://omnihub.xyz/create/arc-testnet)

## Что делать

1. Получай USDC через Faucet
2. Создай свою NFT-коллекцию
3. Заминть 5–10 NFT
4. Используй Bridge (если нужно)

**Очень рекомендуется** — создание своей коллекции считается сильной активностью.
