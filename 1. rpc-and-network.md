# Настройка сети Arc Testnet (RPC + Параметры)

## Основная информация

**Network Name:** Arc Testnet  
**Chain ID:** `5042002`  
**Native Token:** USDC (используется как gas)

### Рекомендуемые RPC

**Основной RPC:**
https://rpc.testnet.arc.network


**Альтернативные RPC:**
https://arc-testnet.rpc.caldera.xyz
https://testnet.arc-rpc.com


## Как добавить сеть в MetaMask / Rabby

1. Открой кошелёк → Networks → Add Network
2. Вставь данные выше
3. Сохрани

**Совет:** Добавь сразу 2–3 RPC, чтобы переключаться при проблемах с нагрузкой.
